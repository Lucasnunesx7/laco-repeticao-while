#laco-repeticao-while
# Resolução de Desafios: Estruturas de Repetição em JavaScript
Este repositório contém os programas que desenvolvi para praticar estruturas de repetição em JavaScript, focando em validação de dados e lógica de controle.

1. Validação de Número Positivo
Usei o while para travar o programa até que um número positivo seja digitado. Se for negativo, ele pede novamente.

2. Média de Notas
O programa recebe notas de 0 a 10 indefinidamente. Quando um número negativo é digitado, o laço para e exibe a média de tudo o que foi inserido.

3. Totalizador de Compras
Um somador onde o usuário insere os valores das compras. O programa só encerra e mostra o total acumulado quando o número 0 é digitado.

4. Validação de Nome e Sobrenome
O algoritmo pede nome e sobrenome separadamente. Se qualquer um ficar vazio, ele repete a pergunta até que o preenchimento esteja correto.

5. Simulação de Saque
Com um saldo inicial definido, o programa permite saques sucessivos. Ele valida se há saldo suficiente e encerra a operação assim que o saldo zerar.

## 🛠️ Tecnologias e Ferramentas:
* **Linguagem:** JavaScript (.js)
* **Lógica:** Estruturas `while`.
* **Versionamento:** Git (comandos `add`, `commit` e `push` para o repositório remoto).
